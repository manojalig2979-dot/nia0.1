Questions & Answers

Frequently Asked Questions

How does Nia protect my data compared to Claude Computer Use?

Claude's computer use feature works by capturing your entire screen and uploading the video/image stream to Anthropic's servers every few seconds. If an email, password, or banking tab is visible, it gets uploaded. In contrast, Nia never streams desktop screenshots to remote LLMs. Nia executes locally using typed Windows APIs, AST code inspections, and OS handles.

Do I need an expensive NVIDIA RTX GPU to run Nia?

No. Nia is engineered to be lightweight. The speech recognition uses Whisper's optimized base model, speech synthesis uses Microsoft Swara Neural, and the agent orchestrator connects to Gemini Flash with sub-second latency over text-only queries. It runs smoothly on standard modern laptops with 4GB+ RAM.

How does WhatsApp integration work?

Nia maintains a dedicated, persistent browser profile in nia_browser_profile/. You scan the QR code once during setup. After that, Nia can read notifications, reply, and dispatch screenshots directly in the background without needing a third-party paid WhatsApp API.

How does the 7-Day Test Flight (₹99 / $1) work?

The 7-Day Pro Test Flight is an introductory ₹99 / $1 pass that unlocks 100% unrestricted access to all Nia Pro capabilities — including WhatsApp automation, AST coding supervisor, 3D talking avatar, and Swara Neural voice on your Windows PC. Once you start your test flight, you receive an instant license key to activate Nia. After 7 days, you can continue with Nia Pro (₹1,799/mo) or upgrade to the permanent Lifetime BYOK Pass (₹6,999) with zero recurring subscriptions.

Where do I get a free Google Gemini API key?

You can generate a free API key in under 30 seconds from Google AI Studio. Google provides generous free tiers for Gemini 1.5 Flash (15 free requests per minute), meaning you can run your desktop assistant every day with ₹0 in API costs.
